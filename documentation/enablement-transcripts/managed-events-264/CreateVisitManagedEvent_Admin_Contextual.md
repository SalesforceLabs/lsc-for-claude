Hello, my name is Crystal Deshpande and I'm a Product Manager on Agent Force Life Sciences. The Create Visit from Managed Event feature helps customers capture HCP interactions that occur during or around a field event. Admins can configure when the Create Visit action is available based on the Managed Event workflow stage or event status and which event colleague roles can create the visit from the event. They can also control which attendees are eligible based on attendance status. To enable this feature, we start with the Event Management Admin console. Once we're in the Admin console, in the Field Events Profile settings, we have a new setting for Visit Settings, Allow Attendant Statuses for Visits. So here we're going to add the allowed attendance statuses for the attendees. So any attendee that is within this attendance status would be eligible to be selected for creating the visit from the Managed Event. So once this is set, we're going to save this and we are going to go to the Workflow Configuration Admin console. And here we're going to go ahead and create a new workflow action for Create Visit. So here we're going to click on New and create an open component action. We're going to provide a name for the action and then we're going to provide the button label. So this is the actual label that will be displayed for the end users. And here, for the object, we're going to select Managed Event. And here we're going to add the component name which gets launched when clicking on the Create Visit action. Now you will see that our action has been created. Once the action is created, we need to now add that action in the applicable workflow path stage. So we're going to go into the workflow path and we're going to pick the stage where we want this action to be added. So since the Create Visit action should be available either during the visit or after the visit, I'm going to go ahead and add it in the Execute Status. For stage operation actions, I would go ahead and add this Create Visit action. We want to ensure that the appropriate roles are already configured and that way those roles have access to this action. If there's any other statuses where this action needs to be configured, you can go ahead and do that the same way. So I've configured it here in the Execute and Concluded statuses. So now with this configuration in place, event organizers can then capture individual or group visits directly from a managed event with less duplicate entry and more consistent process. Thank you.
