Hello, my name is Crystal Deshpande and I'm a product manager on Agent Force Life Sciences. The estimated expense allocation feature helps customers plan event costs before an event occurs and understand how those projected expenses are distributed across participants. Admins can configure which expense types are available for estimates and actuals on a managed event. Whether expenses can be allocated evenly or unevenly, whether partial allocation is allowed. In this demo, I'll show you the setup of estimated expense types for a managed event and prepare the experience that event organizers will use to capture and allocate estimated costs. To begin with, as a prerequisite, we want to make sure all the appropriate expense types for managed events are created. So when creating an expense type for a managed event, the expense availability type has to be indicated as managed event. And also, we want to make sure the classification is either actual or estimate. Actuals are line items and estimates are categories. So we want to make sure that the estimate expense type, which is the category or the parent, is indicated as the parent expense type for the actual. This way, when the event organizer selects an estimate and then later wants to add an actual, the actual is created then with the parent estimate. It's important to also set the allocation type as either individual, multiple, or no allocation. For something like a food and beverage expense type, multiple allocation makes sense since you would be allocating a food and beverage cost across multiple participants. But something like a speaker fee or an expert fee, an individual allocation makes sense since you would be allocating the actual cost for the individual speaker. Once the expense types are all set up, then we need to go to the events management admin console and go to the field events profile settings. Here, we've introduced a new setting for the estimated expense allocation invitation status. You'll see the setting now included under the allocations settings. Here, you will indicate the invitation statuses for which those specific attendees would be available for estimated expense allocation. Ensure any of the existing settings that are available have been configured and then make sure you save these settings. Now, with this configuration in place, event organizers can go ahead and allocate estimated costs to participants. Thank you.
