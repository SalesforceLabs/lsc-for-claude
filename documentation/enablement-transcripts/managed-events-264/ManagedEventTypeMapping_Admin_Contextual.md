Hello, my name is Crystal Deshbande and I am a product manager on Agent Force Life Sciences. Managed event type mapping is a winter 27 feature designed specifically for customers who use or plan to use managed event record types. As a reminder, record types give customers greater flexibility in tailoring the event experience. Each managed event record type can support different workflow paths and different Lightning record pages, allowing the experience to reflect the needs of each type individually. With this feature, administrators can map each managed event record type to one managed event type. When an event organizer selects a mapped record type, the system automatically assigns the corresponding managed event type in the background. This reduces manual entry for field users and promotes consistent event classification across web and mobile. Let's jump into the setup of managed event types mapping. As a prerequisite, we want to make sure that the record types are set up for the managed event entity. So within Object Manager, Managed Event Object, you want to set up your record types. Once the record types are set up, you want to set up all the managed event types. So you want to go to the Managed Event Types entity and you want to go ahead and set up those individual managed event types that are required by the customer. Once those managed event types are set up, we want to set up the mapping and for us to do that, we need to make that available in the admin console. So for that, we need to go to Setup, we need to go to Life Sciences for Customer Engagement Setup, and when you scroll down, you see here Configure Event Management for Customer Engagement. When you expand that, you see a setting for Autopopulate Managed Event Type in Managed Records. Once you enable this setting, then this makes it available in the admin console. For us to go ahead and then do that mapping. So in the admin console, you want to go to the Event Management tile. Once you're in the Event Management tile and when that setting has been enabled, this Event Type Mappings tab becomes available. Here within this admin console, then we are able to go ahead and do that one-to-one mapping. It's pretty straightforward, it's just selecting the record type and then selecting the correlating event type. Once this mapping is in place, it makes it easier for event organizers to go ahead and initiate that event and not have to manually enter or select the event type. Now say that the record type has changed. After a few days or over time, a new record type has been created and an older record type now doesn't need to exist. In that case, we don't have a way to delete this mapping. The reason for that is we don't want any existing events that have been created to get affected by that. So the way to do it is to deactivate the mapping and then create a new mapping for the new record type that has been created. Or vice versa. If a new event type has been created, then the same logic would apply there. After all of the mappings are in place, there's only one last step left and it is to remove the Managed Event Type field from the Managed Event Page Layout since we no longer need it. So I'm going to go to the Managed Event Page Layout and I will go ahead and remove this Managed Event Type field and save this. Okay, that's it. That concludes the setup of the Managed Event Types Mapping feature. Thank you.
