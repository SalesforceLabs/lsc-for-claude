Hello, my name is Crystal Deshpande and I am a product owner on Agent Force Life Sciences. The participant type mapping features design so that customers can standardize how participants are classified across different kinds of managed events. Different event types can require different categories of participants and different roles. For example, a speaker event might include HCP attendees, speakers, internal colleagues, write-in attendees, and non-profiled attendees. The valid participant classifications may differ from those used for a Congress or another type. With participant type mapping, administrators define the valid participant types, roles, and combination for each managed event type. Then, they can also configure a default role for each participant type where applicable. When an event organizer adds someone to an event, the system automatically applies the configured participant record type, participant type, default role, and type role mapping. This reduces manual entry while improving data quality and reporting consistency and compliance. Let's jump into the setup of the participant type mapping. First, let's make sure all the prerequisites are completed before we can do the participant type default mapping. In the event management participant role object, we have a role field and this is a dynamic enum so the customers would configure their own custom roles that are applicable for their business. Once they've set up these roles, then they would do the same for the event management participant type. In the type field, they would go ahead and create their custom participant types. Once the participant roles and the participant types have been created, then we need to map those custom participant roles and custom participant types to our system standard roles and system standard types. For that, we have an event management participant roles mapping where you would map the role with the standard type and then the same would need to be done with the event management participant types. Optionally, you could also set up record types for the managed event participants. So far, all of the setup that has been done has already been part of the product.
